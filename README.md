
Clon de Tarjetas de Precios de Spotify
Descripción del Proyecto
Este proyecto es una recreación de la sección de tarjetas de precios de Spotify, diseñada utilizando HTML y CSS. El objetivo principal es replicar el diseño visual de las opciones de suscripción que ofrece Spotify, incluyendo la disposición de las tarjetas, los colores, la tipografía, y los efectos interactivos.

Este proyecto fue desarrollado como parte de la asignatura Laboratorio 3 de la Tecnicatura en Programación.
